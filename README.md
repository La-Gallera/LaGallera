# La Gallera

Versión completa preparada para un repositorio con todos los archivos en la raíz.

Descomprimir el ZIP y subir TODOS los archivos directamente a GitHub. No subir el ZIP ni una carpeta contenedora.

index.html, menu.html, menu-impreso.pdf y todas las imágenes e iconos deben quedar al mismo nivel. Los nombres de archivo no se deben cambiar.

Publicar desde Settings > Pages > Deploy from a branch > main > / (root) > Save.
